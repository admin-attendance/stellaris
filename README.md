# Stellaris Air

Stellaris Air 콘셉트 웹사이트입니다.

- Seom Air·대한항공 계열의 정돈된 항공사 UX를 참고하되, 브랜드·로고·레이아웃은 독자적으로 구성
- 올리브/세이지 기반 컬러 시스템
- 반응형 데스크톱·모바일 레이아웃
- 항공권 검색 UI, 왕복/편도 전환, 출발/도착지 스왑
- 여행지, 기내 경험, A321neo 소개, 뉴스레터 섹션
- 외부 사진 없이 SVG/CSS 아트로 구성

## GitHub Pages 배포

Repository **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `(root)`를 선택하고 저장하면 됩니다.

## Files

- `index.html` — 페이지 구조
- `styles.css` — 디자인 및 반응형 스타일
- `app.js` — 기본 인터랙션
